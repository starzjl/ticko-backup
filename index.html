Ticko Personal Backup

A private desktop backup utility operated by starzjl for backing up the owner’s local files to the owner’s Google Drive.

Restic encrypts and deduplicates files locally. Rclone transfers the encrypted repository. Google Drive access supports uploading backups, reading historical snapshots, restoring files, and removing expired backup objects.

This is a personal utility, not a public hosted service. This website contains no work files, backup contents, passwords, OAuth credentials, or tokens.
