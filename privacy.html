Privacy policy

Last updated: 14 October 2026

Ticko Personal Backup is a personal desktop utility operated by starzjl, solely for the operator’s own Google account and local files.

Access and use

The utility accesses Google Drive file metadata and contents to create, list, read, update and delete encrypted backup repository objects. Full Drive access supports migration and restoration of backup files created under another OAuth client. Routine operations target the designated backup repository.

Storage and security

Restic encrypts file contents locally before uploading to Google Drive. Backup data and metadata are stored encrypted in the operator’s Drive. OAuth credentials and the backup password are stored locally in files with restricted permissions. Logs and restored files may remain locally. The operator must secure the computer and separately preserve the encryption password.

Sharing and limited use

The utility does not sell Google user data, use it for advertising, or use it to train AI models. Data is used only for backup and restoration. Encrypted files are transmitted to Google Drive at the owner’s direction; no additional hosted backend receives them. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Snapshots are retained under the configured hourly, daily, weekly and monthly policy. The operator may delete the repository from Drive and revoke access in Google Account settings. Revoking access alone does not delete backups. Deleted Drive objects may remain in Trash under Google’s retention behavior.

Website and contact

This static website has no analytics or forms and contains no backup data or credentials. GitHub Pages may process normal request information under GitHub’s privacy policy. Contact the operator through the GitHub profile.
